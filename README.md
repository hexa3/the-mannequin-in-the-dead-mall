# The Mannequin in the Dead Mall

A horror game told entirely as a text conversation.

Your friend Mira has broken into Fairhaven Galleria, a mall that closed in 2011. The lights are off, but the music is still playing. There's a mannequin, and it's never where she left it.

**[Play it here](https://hexa3.github.io/the-mannequin-in-the-dead-mall/)** · headphones on, lights off, about 20 minutes.

- One self-contained `index.html`: no build step and no assets
- All music is synthesized live with Web Audio, and every photo is drawn in SVG
- 6 endings
